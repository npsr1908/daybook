# Daybook

A local-first personal finance tracker with editable accounts, transactions, budgets, and analytics.

## Open the app

Open `index.html` in a modern browser. No install, sign-in, or network connection is required.

## Your data

- Transactions and settings are saved in the current browser profile on this device.
- **Back up your data** downloads a JSON backup. **Restore a backup** loads one into the app.
- **Start fresh** downloads a backup before clearing transactions and resetting account opening balances.
- The app does not connect to banks or send financial data to a server.
- Starter account names are HDFC Bank, HDFC CC, Wallet, and FD, each with a zero opening balance. You can rename or remove them and add your own accounts.
- Starter budget categories use zero monthly limits and can be edited in the app.
